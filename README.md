Uturu OS beta 8

Описание:

Свободная операционная система на архитектуре i386 

Сделана на загрузчике GNU GRUB + самописном ядре на C

Является свободным программным обеспечением под лицензией GNU GENERAL PUBLIC LICENSE Version 3 или выше
Текст лицензии находится в файле LICENSE 

Список команд Uturu OS:
    ver — показать версию ОС
    help — список всех команд
    clear — очистить экран
    fetch — информация о системе (ОС, архитектура, загрузчик, ОЗУ, файлы)
    author — автор и лицензия
    crash — вызвать kernel panic
    shutdown — выключение (показать сообщение о безопасном выключении)
    reboot — перезагрузка
    echo — вывести текст
    calc — запустить калькулятор
    ls — список файлов
    cat — просмотр содержимого файла
    create — создать файл
    edit — редактировать файл
    rm — удалить файл

Всего 15 команд. 

Сборка Uturu OS из исходного кода:
Для сборки операционной системы нам понадобится операционная система GNU/Linux и следующие пакеты:
    GCC — компилятор C
    nasm — ассемблер
    ld (из binutils) — линковщик
    make — система сборки
    grub-mkrescue (из пакета grub2 или grub-common) — создание ISO
    i686-elf-gcc — кросс-компилятор C
    i686-elf-binutils — кросс-линковщик и утилиты
    и запуск команды make all

Сборка на других операционных системах:

Сборка на операционной системе Microsoft Windows не поддерживается!

Сборка на других свободных операционных системах, таких как операционные системы семейства BSD, Haiku OS
или GNU HURD, возможна, но рекомендуется использовать GNU/Linux для компиляции.

Сборка на проприетарной операционной системе macOS возможна, но крайне не рекомендуется.
